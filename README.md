## Overview

**Task Manager Application** is an event-driven desktop To-Do and productivity tool built natively using Java Swing. Designed with a clean, distraction-free aesthetic, it delivers rapid task entry, prioritization, completion toggling, and list state management with zero heavy runtime overhead.

## Key Features

- **Lightweight Native UI**: Native window management via Java Swing (`JFrame`, `JPanel`, `JButton`, `JList`) ensuring instantaneous load times without web-view bloat.
- **Task Lifecycle Management**: Supports instantaneous task creation, status updates, completion markings, and deletion.
- **Event-Driven Architecture**: Responsive UI thread decoupled from action listeners to maintain high framerate interactivity.
- **Cross-Platform Compatibility**: Runs seamlessly on any system with a standard Java Runtime Environment (JRE/JDK on Windows, macOS, or Linux).

## Quickstart

### 1. Prerequisites
* Java Development Kit (JDK 17 or higher)
* Verify installation:
  ```bash
  java -version
  javac -version
  ```

### 2. Clone & Compile
```bash
git clone https://github.com/prannesshkva/Task-Manager-Application.git
cd Task-Manager-Application

# Compile Java source
javac *.java

# Launch desktop application
java TaskManager
```
